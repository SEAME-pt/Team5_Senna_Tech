# Documentation: Car Cluster - Demo (Initial Version)

## 1. Project Description

The **Car Cluster - Demo** is a graphical interface simulating a modern car dashboard.

* Vehicle speed in both analog (dial) and digital formats.

* Battery level with a progress bar and dynamic colors.

* Quick information (time, mode) can be added later.

The project uses **Qt Quick (QML)** for the interface and **C++ (ClusterBackend)** to simulate vehicle data.

## 2. Project Structure

```
CarClusterQt/
├── main.cpp              # Application initialization and simulated backend
├── Main.qml              # Main interface (UI)
├── resources.qrc         # Resources (images, fonts, etc.)
├── CMakeLists.txt        # Build system
└── main.moc              # Meta-object compilation (generated by Qt)
```

## 3. Backend: ClusterBackend (C++)


This class provides dynamic speed and battery data.
### Properties:

| Property   | Type   | Description                   |
| ---------- | ------ | ----------------------------- |
| `speed`    | double | Vehicle speed (0–240 km/h).   |
| `battery`  | int    | Battery level (0–100%).       |

### Signals:

| Signal              | Description                               |
| ------------------- | ----------------------------------------- |
| `speedChanged()`    | Emitted when the speed changes.           |
| `batteryChanged()`  | Emitted when the battery level changes.   |

### Functionality:

* A QTimer updates the values every 100 ms (10 Hz).

* Speed is simulated using a sinusoidal function (sin) oscillating between 0 and 220 km/h.

## 4. Graphical Interface (QML)
The UI is divided into **two main panels**, arranged using a **RowLayout**:

### 4.1 Left Panel – Speedometer
* Rectangle with green border and dark background (#0f1720).

* Contains a Canvas that draws:

    * Background arc representing the dial.

    * Ticks distributed along the arc.

    * Progress arc proportional to the current speed.

    * Central text: speed and unit Km/h.

* The Canvas updates dynamically via Connections when clusterBackend.speed changes:
```
Connections {
    target: clusterBackend
    onSpeedChanged: dial.requestPaint()
}
```

* Colors and styles of the dial are configured with strokeStyle and gradient.

### 4.2 Right Panel – Battery
* Rectangle with green border (#A7FF0A) and dark background (#071421).

* Contains a centered Column with:

    * Title text: "Battery".

    * Battery level bar (Rectangle):

        * Outline defined by barOutline.

        * Fill (barFill) proportional to clusterBackend.battery.

        * Dynamic color:

            * Green (> 50%)

            * Orange (20 – 50%)

            * Red (< 20%)

        * Displays the battery percentage as text (Text) on top.

* Fill width updates automatically via binding:
```
width: (barOutline.width - 4) * clusterBackend.battery / 100.0
```
* Gradient colors change based on battery level:
```
GradientStop { position: 0.0; color: clusterBackend.battery > 50 ? "#A7FF0A" : clusterBackend.battery > 20 ? "#FF6403" : "#FF0303" }
```

## 5. Style and Appearance

* Main colors: dark backgrounds (#0b0f14, #0f1720, #071421), green/orange/red for highlights.

* Rounded corners: radius on panels and bars.

* Typography: sans-serif with varying sizes (36px for speed, 24px for units).

* Responsive layout: uses Layout.preferredWidth and Layout.fillHeight to adapt to window size.

## 6. Dynamic Updates
* ClusterBackend emits signals when values change:

    * speedChanged() → updates the dial.

    * batteryChanged() → updates the battery bar.

* Bindings and Connections ensure real-time interface updates.

## 7. Execution

* Compile the project with Qt 6:

    ```
    mkdir build
    cd build
    cmake -DCMAKE_PREFIX_PATH=/.../Qt/6.9.3/gcc_64 ..
    cmake --build .
    ./appCarClusterQt
    ```

* The interface opens showing:

    * Speedometer with ticks and progress arc.

    * Battery bar filled according to the current level.

## 8. Notes and Future Improvements
* Speedometer needle: not implemented yet.

* Additional info: time, driving mode, gear can be added in the right panel.

* Cross-compilation: needed to run on Raspberry Pi 5.

* External fonts: e.g., Orbitron for a futuristic style.

* Smooth animations: interpolate speed and battery bar for a smoother visual.
