# Descrição:
# Log de teste automatizado validando que o instrument cluster mantém
# a indicação visual de warning visível durante toda a duração da condição crítica.
#
# O teste executa o seguinte fluxo:
#  1. Injeta condição crítica (bateria abaixo de 5%).
#  2. Verifica ativação do warning visual no cluster.
#  3. Mantém a condição crítica ativa por 15 segundos simulados.
#  4. Confirma que o warning permanece visível durante todo o período.
#  5. Remove a condição crítica.
#  6. Verifica que o warning é removido imediatamente após a normalização.
#
# Critérios de aceitação:
#  - Warning não pode desaparecer enquanto a condição crítica existir.
#  - Warning deve desaparecer apenas após condição deixar de ser crítica.
