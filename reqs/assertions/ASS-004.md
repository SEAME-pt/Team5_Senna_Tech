## Description
This assertion verifies that the Qt graphical interface accurately displays the vehicle's current speed in real time.  
The speed indicator must reflect the actual value provided by the speed sensor
## Verification Criteria
- The speed value displayed on the Qt interface matches the real-time vehicle speed readed from the sensor
- The displayed speed updates smoothly.  
- Units of measurement (e.g., km/h) are displayed correctly.  
- The speed display remains legible and visually stable on the target embedded screen.
