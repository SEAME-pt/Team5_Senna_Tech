## Description
This assertion verifies that the Qt graphical interface correctly displays the vehicle's battery level in real time.  
The battery indicator must show the current charge percentage, update dynamically according to sensor data, and notify the user in case of low battery level or charging state changes.

## Verification Criteria
- The battery level value displayed on the Qt interface matches the real battery data received from the system.
- The displayed information updates correctly after de system identifies any changes.
- The interface layout and battery indicator remain stable and readable on the target embedded screen.
