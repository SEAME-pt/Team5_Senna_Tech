# Creation of the Speed Sensor Reading Thread

## Objective
The speed sensor reading thread (sensor_thread) aims to monitor pulses generated by an encoder (speed sensor) connected to pin PB0 and calculate the rotations per minute (RPM) of the rotating shaft.

## Thread Structure

#### 1. Thread and Stack Definition

In app_threadx.c, the thread is declared as:
```
TX_THREAD sensor_thread;
UCHAR sensor_thread_stack[1024];
```
- TX_THREAD sensor_thread: Structure representing the ThreadX thread.

- UCHAR sensor_thread_stack[1024]: Memory allocated for the thread stack. The size can be adjusted depending on the thread's complexity.

#### 2. Thread Function Prototype

The function implementing the thread is defined as:
```
void sensor_thread_entry(ULONG thread_input);
```
- thread_input: Parameter passed during thread creation. Not used in this case (passed as 0).

#### 3. Thread Creation

The thread is created using tx_thread_create inside App_ThreadX_Init:
```
tx_thread_create(&sensor_thread,
                 "Sensor Thread",             // Thread name
                 sensor_thread_entry,         // Thread entry function
                 0,                           // Thread argument
                 sensor_thread_stack,         // Pointer to the stack
                 sizeof(sensor_thread_stack), // Stack size
                 0,                           // Thread priority
                 0,                           // Preemption priority
                 TX_NO_TIME_SLICE,            // Time slice disabled
                 TX_AUTO_START);              // Automatically start the thread
```

#### Key parameters:
| Parameter                    | Description                                                         |
|------------------------------|---------------------------------------------------------------------|
| `sensor_thread`              | Thread structure                                                    |
| `"Sensor Thread"`            | Descriptive name of the thread                                      |
| `sensor_thread_entry`        | Function executed by the thread                                     |
| `0`                          | Argument passed to the thread                                       |
| `sensor_thread_stack`        | Pointer to the stack buffer                                         |
| `sizeof(sensor_thread_stack)`| Size of the stack                                                   |
| `3`                          | Thread priority (ThreadX: lower number = higher priority)          |
| `3`                          | Preemption priority                                                 |
| `TX_NO_TIME_SLICE`           | Thread does not have a time slice                                   |
| `TX_AUTO_START`              | Thread starts automatically after creation                          |

#### 4. Thread Implementation

The main thread function is sensor_thread_entry:
```
void sensor_thread_entry(ULONG thread_input)
{
    while(1)
    {
        uint32_t current_time_ms = tx_time_get();

        if(current_time_ms - last_time_ms >= 100) // every 100 ms
        {
            uint32_t diff = pulse_count - last_pulse_count;
            last_pulse_count = pulse_count;
            last_time_ms = current_time_ms;

            // Calculate RPM
            rpm = (int)(((float)diff / PULSOS_POR_ROTACAO) * 60.0f);

            // Periodic printing
            if (tx_time_get() - last_print >= 200)  // every 200 ms
            {
                last_print = tx_time_get();
                printf("Average RPM: %d | Pulses: %lu\r\n", rpm, pulse_count);
            }
        }
    }
}
```

#### Explanation:

##### **1. Time reading:**
current_time_ms = tx_time_get(); returns the current ThreadX kernel tick count.

##### **2. Sampling period:**
The thread checks if 100 ms have passed since the last read.

##### **3. Pulse difference calculation:**
```
diff = pulse_count - last_pulse_count;
last_pulse_count = pulse_count;
```

##### **4. RPM calculation:**
Considers PULSOS_POR_ROTACAO (number of holes in the encoder) and converts pulses into RPM:

`RPM = (pulses_in_interval / pulses_per_rotation) * 60`



##### **5. Periodic printing:**
Every 200 ms, prints the average RPM and total pulse count to the console.

#### 5. Interaction with EXTI Interrupt

Pulse count is incremented in the external interrupt callback:

```
void HAL_GPIO_EXTI_Rising_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == GPIO_PIN_0) // PB0 -> EXTI0
    {
        pulse_count++;
    }
}
```

- Each sensor pulse increments pulse_count.

- The sensor thread uses pulse_count to calculate RPM.

### Considerations

- Thread priority (0) should be lower than the LED threads (1 and 5) to avoid blocking.

- The thread uses polling every 100 ms to calculate RPM. This can be optimized with semaphores or events if needed.

- The pulse_count variable is volatile, ensuring correct access between the interrupt and the thread.
