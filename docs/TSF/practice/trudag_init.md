## ⚙️  Install Trudag and Create the Environment

A setup script is provided at:  
`scripts/trudag/trudag_env.sh`

It handles the creation of a Python virtual environment and installs Trudag automatically.

### Step 1 — Make the script executable
Run the following command to give execution permission to the setup script:

```bash
chmod +x scripts/trudag/trudag_env.sh
```

### Step 2 — Make the script executable

```bash
source venv/bin/activate
```

### Step 3 — Trudag init

```bash
trudag init
```

### Congratulations! 

### Now you're able to start working with trudag.
