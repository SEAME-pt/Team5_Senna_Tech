## Overview
Processes the raw outputs of the lane segmentation model and converts them into a clean binary mask of the lanes.

## Module
`lane_post_processing.py` consolidates the two classes of this stage:
- `YoloSegDecoder`
- `MaskFilters`

### `YoloSegDecoder`
Responsible for identifying the format of the segmentation model tensors and reconstructing the lane mask.

#### `__init__(score_threshold=0.25, top_k=200)`
Defines the thresholds used to select candidates and limit the number of masks considered.

**Parameters**
- `score_threshold` defines the minimum threshold to keep a mask proposal.
- `top_k` limits the number of candidates considered in the reconstruction.

**Effects**
- Stores the thresholds to be used in `decode_to_mask`.

#### `decode_to_mask(outputs, orig_h, orig_w)`
Receives raw inference tensors and returns a binary mask of the road/lanes.

**Behavior**
- Automatically identifies the format of output tensors.
- Reconstructs the mask using proto features and mask coefficients.
- Applies score selection and confidence threshold.
- Resizes the final result to the original frame resolution.

**Inputs**
- `outputs`: dictionary with the raw model tensors.
- `orig_h` and `orig_w`: dimensions of the original frame.

**Output**
- `numpy.ndarray uint8` with the lane binary mask.

### `MaskFilters`
Responsible for cleaning the binary mask using morphological operations.

#### `__init__(close_kernel=(5, 15), open_kernel=(5, 5))`
Configures the morphological kernels used in mask cleaning.

**Parameters**
- `close_kernel` defines the kernel for morphological closing.
- `open_kernel` defines the kernel for morphological opening.

**Effects**
- Creates rectangular kernels used in `process`.

#### `process(mask)`
Applies morphological closing and opening to reduce noise and fill gaps.

**Behavior**
- Executes `MORPH_CLOSE` to fill small holes and join separated regions.
- Executes `MORPH_OPEN` to remove noise and isolated artifacts.

**Input**
- `mask`: binary mask generated by the decoder.

**Output**
- Cleaner and more stable binary mask for the geometry stage.

## Data Contract
| Field | Type | Meaning |
|---|---|---|
| `outputs_lane` | `dict` | Raw tensors from the lane segmentation model |
| `binary_mask` | `numpy.ndarray uint8` | Lane binary mask |

## Debug

Both classes accept a `debug=False` flag in their constructors.

### Lifecycle logs
None — this module does not emit lifecycle logs.

### Per-frame logs (`debug=True`)

#### `YoloSegDecoder`
| Event | Level | Message |
|---|---|---|
| Mask threshold applied | `DEBUG` | `[YoloSegDecoder] Mask mean: X.XXXX, threshold: X.XXXX` |

#### `MaskFilters`
| Event | Level | Message |
|---|---|---|
| Filtered mask stats | `DEBUG` | `[MaskFilters] Post-filter non-zero pixels: XXXX` |

### How to enable
```python
decoder = YoloSegDecoder(score_threshold=0.3, debug=True)
filters = MaskFilters(debug=True)
```
And ensure the logging level is set to `DEBUG`:
```python
logging.basicConfig(level=logging.DEBUG)
```

## Notes
- This layer acts as the bridge between `inference` and `LFA`.
- Tensor format details are encapsulated here.
