## 🧩 About the Project

The **WarmUp** project is focused on developing an autonomous car.
Our initial goal is to get the vehicle moving in a controlled way while structuring the repository and documenting the entire process to ensure collaborative and organized development.

## 🎯 First Sprint Goals (2 weeks)

- Get the car **moving** (basic motion control)
- **Organize GitHub** with branches, standardized commits, and an initial README
- Create and maintain the project’s **technical documentation**

## 🧠 Organization and Workflow

- **Main branch:** `main`
- **Development branch:** `dev`
- **Feature branches:** `feature/feature-name`
- **Commits:** should follow a descriptive pattern (e.g., `feat: adds motor control`)

## ⚙️ How to Execute
```bash
# Clone the repository
git clone git@github.com:SEAME-pt/Team5_Senna_Tech.git

# Enter the folder
cd Team5_Senna_Tech

# (Optional) Set up the environment
# Example: install dependencies, activate venv, etc.

# Run the main code
python src/main.py
```
